# Welcome to KbWrite

KbWrite is a local-first knowledge base. Your notes are plain markdown files in a folder on your computer.

## Quick start

- Create notes from the sidebar, or press `Cmd/Ctrl+N`.
- Write in the block editor. Type `/` for headings, lists, to-dos, quotes, code, and more.
- Save with `Cmd/Ctrl+S`. KbWrite also saves when you switch notes or quit.
- Change the vault folder in Settings (`Cmd/Ctrl+,`).

## Linking notes

Type `/` and choose **Link to note**, or write a wikilink yourself: `[[Welcome]]`.
Open **Graph** to see how notes connect.

## Inline AI

1. Open Settings and add an OpenAI-compatible base URL, model, and API key
   (OpenAI, Ollama, LM Studio, OpenRouter, and others).
2. Press `Cmd/Ctrl+I` or click **AI Assist**.
3. Ask for something like "Fix grammar" or "Turn into bullets".
   The result is inserted below the block you were editing.
