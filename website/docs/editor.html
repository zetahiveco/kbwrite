The editor

A block editor over plain markdown. Everything you can type is stored as text you can read in any other tool.

Blocks and the slash menu

A note is a list of blocks: paragraphs, headings, lists, to-dos, quotes, tables, code fences, images, video, audio, PDF, CSV, DOCX, and XLSX. Press / on an empty line (or at the start of text) to open the block menu; type to filter it. Drag the handle at the left of a block to reorder, or select several and turn them into a list, a quote, and so on.

Files dropped or pasted into a note are stored inside the vault and referenced from the note.

Math

Type LaTeX between dollar signs and it renders as you write, with KaTeX: $E = mc^2$ inline, or a display block from / → Math: 

$$
\int_{-\infty}^{\infty} e^{-x^2}\,dx = \sqrt{\pi}
$$

Inline math stays editable in place — click it to change the LaTeX. The markdown on disk keeps the plain $…$ and $$…$$ syntax, so other tools render it too.

Mermaid diagrams

A mermaid code fence becomes a live diagram. Edit it with the Edit source button on the block: 

```mermaid
graph TD
    A[Idea] --> B{Worth keeping?}
    B -- yes --> C[Note]
    B -- no --> D[Trash]
```

Flowcharts, sequence diagrams, gantt charts, and the rest of the Mermaid grammar all work.

Code blocks

Fenced code blocks are syntax highlighted with Shiki for dozens of languages. Set the language from the picker at the top of the block; the language is stored in the fence, exactly as you would write it by hand: 

```ts
export function greet(name: string): string {
  return `Hello, ${name}!`;
}
```

Wikilinks

Type [[ and start writing a note name — KbWrite completes notes in the vault and creates the link. Clicking a wikilink opens the note; if it does not exist yet, it is created. Regular markdown links work as well, and both feed the graph view.

Images and media

Paste or drop an image and it is saved into the vault (referenced with a kbwrite-media:/// URL that stays valid inside the folder). Video, audio, PDF, CSV, and spreadsheet files embed the same way.

Raw markdown

The toolbar toggle (or Raw markdown in the palette) swaps the block editor for a plain textarea on the same file. Edit the raw text, switch back, and the block editor picks up your changes. This is also the escape hatch for anything the blocks do not cover.

Formatting with Prettier

Format note (Prettier) in the command palette tidies the markdown of the current note — consistent lists, spacing, and wrapping. Turn on Auto-format markdown on save in Settings to do this every time you save.
