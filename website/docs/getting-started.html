Getting started

From zero to your first note in about two minutes.

On this page
  • Install
  • Choose a vault
  • Write your first note

  • Updates

Install

macOS and Linux install with one shell command, Windows with one PowerShell command. See the install box on the home page — it detects your platform.

The installers download the latest signed release from GitHub Releases. On macOS the app is copied into /Applications; on Linux the binary lands in ~/.local/bin; on Windows an installer opens.

Choose a vault

When KbWrite first opens it creates a vault at Documents/KbWriteVault. A vault is just a folder — the app reads every .md file in it, including subfolders.

To use an existing folder of notes (say, exported from another app), open ⌘, / Ctrl+, Settings and set the vault path, or click the vault path in the sidebar footer. KbWrite watches the folder, so changes made outside the app show up on their own.

Write your first note

  1. Press ⌘N / Ctrl+N (or the new-file button above the sidebar) and give the note a name.
  2. Type. Press Enter for a new block, / for the block menu: headings, lists, to-dos, quotes, tables, code, images, and more.
  3. Link to another note by typing [[ and part of its name, or use / → Link to note.
  4. ⌘S / Ctrl+S saves. Auto-save also runs as you edit.

Notes are markdown under the hood — switch to Raw markdown from the toolbar or the palette to see and edit the exact file contents.

Where your notes live

Every note is a single .md file inside the vault, named after the note. Images and other attachments are stored in the vault too, so the folder is complete and portable: copy it, sync it, or put it in git and nothing is left behind.

Updates

KbWrite checks for updates automatically and can also check from the app menu. Updates are downloaded as signed artifacts from GitHub Releases.
