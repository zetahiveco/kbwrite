Documentation

KbWrite is a local-first knowledge base: a block editor on top of plain markdown files in a folder on your machine. Nothing leaves your disk unless you send it somewhere yourself.

The idea

Most note apps put your writing in a database only they can read. KbWrite does the opposite: the vault is a plain folder, and every note is a normal .md file. KbWrite renders and edits them with a block editor, and anything else — git, another editor, a script, a backup tool — can work on the same files at the same time.

The features you would expect from a knowledge base are all there: wikilinks between notes, a graph of how notes connect, full-text search, bookmarks, and a command palette that keeps your hands on the keyboard.

Quick start

  1. Install KbWrite — one command on macOS, Linux, or Windows.
  2. Open it and pick a folder for your vault (or accept the default in Documents).
  3. Press ⌘N / Ctrl+N for a new note and start typing. Press / to see everything a block can be.
  4. Press ⌘P / Ctrl+P any time to see what the app can do.
