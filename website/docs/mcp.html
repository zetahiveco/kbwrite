MCP server

Let your AI assistant read and write the vault through the Model Context Protocol.

On this page
  • Start the server
  • Connect an assistant
  • The tools
  • What it can and cannot do

Start the server

Open Settings and press Start under MCP server. KbWrite listens on http://127.0.0.1:47321/mcp — local only, and scoped to the open vault. The server stops when you press Stop or quit KbWrite.

Connect an assistant

Settings shows the exact command for each supported assistant; run it once in a terminal:

# Claude Code
claude mcp add --transport http kbwrite http://127.0.0.1:47321/mcp

# Codex
codex mcp add kbwrite --url http://127.0.0.1:47321/mcp

# OpenCode
opencode mcp add kbwrite --url http://127.0.0.1:47321/mcp

The assistant can then use the vault as a tool: list notes, search them, and create or edit markdown. Start KbWrite and the server before a session; the MCP registration itself persists.

The tools

ToolWhat it does
list_notesEvery markdown note in the vault, by relative path.
read_noteRead one note's markdown.
search_notesFull-text search across the vault.
create_noteCreate a note with a title and optional content.
write_noteReplace a note's markdown.
delete_noteDelete a note.

Paths are relative to the vault, like Welcome.md or Meeting Notes/Standup.md.

What it can and cannot do

The server only exposes the open vault, only while KbWrite is running, and only on your machine. It cannot see other folders, and nothing is uploaded anywhere by KbWrite itself. Whatever the assistant does with the notes it reads is governed by that assistant's own privacy policy — the vault is plain text on your disk, so treat prompts accordingly.

Tip: good first prompts are "summarize what I wrote this week", "find notes that mention X and link them to the new overview note", or "turn these meeting notes into tasks".
