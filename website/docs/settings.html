Appearance

Dark mode on or off, plus typography: an interface font, an editor font, and the editor font size (10–40 px). The interface font changes menus, sidebar, and dialogs; the editor font applies to the note text itself. Leave a font empty to use the system default.

Editing

Auto-format markdown on save runs the current note through Prettier each time you save, so lists, emphasis, and spacing stay consistent even if the raw file was edited elsewhere. Prefer doing it by hand? Format note (Prettier) is in the command palette.

Custom CSS

The Custom CSS box injects your stylesheet on top of the theme — adjust the editor width, spacing, colors, anything: 

/* your CSS */
.editor-frame { max-width: 46em; }
.bn-block-content { letter-spacing: 0.02em; }

Changes apply immediately. Use it for small tweaks or a full personal theme; combine it with the font settings for a setup that feels like yours.

Vault

The vault path points at the folder of markdown notes KbWrite opens at startup. Change it here or click the path in the sidebar footer, then Browse. KbWrite re-reads the folder when files change outside the app, so pointing it at a folder that another tool also edits is safe.

MCP server

The bottom section runs a local MCP server. Press Start and copy the one-line setup command for Claude, Codex, or OpenCode. The server can only see the open vault, and only while KbWrite is running.

Plugins

Install a plugin from a folder or paste a GitHub URL; installed plugins can be disabled or removed from the same list. See the plugin docs for the API and a walkthrough.
