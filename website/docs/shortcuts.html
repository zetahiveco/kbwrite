Palette & shortcuts

One input for everything: commands, files, and full-text search.

On this page
  • Command palette
  • Go to file
  • Global search
  • Keyboard shortcuts

Command palette

Press ⌘P / Ctrl+P for the palette. It lists commands — new note, save, format with Prettier, read-only view, zen mode, graph view, bookmarks — plus every note in the vault. Type to filter, ↑/↓ to move, Enter to run, Esc to close. Plugin commands appear here too.

Go to file

⌘O / Ctrl+O opens the palette in file mode. Type part of a note name; matches show their folder, and Enter opens the selection. It is fuzzy, so proj alph finds Project Alpha.

Global search

⌘⇧F / Ctrl+Shift+F searches the contents of every note. Results are lines with their note and line number; pick one to jump straight to it. Wikilink syntax is searchable too, so you can find every note that references another.
