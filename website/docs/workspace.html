The workspace

The sidebar, the graph, and the view modes around the editor.

On this page

  • Bookmarks
  • Graph view
  • Zen mode
  • Read-only view
  • Light and dark

Sidebar

The sidebar lists every note and folder in the vault. Filter it with the Search notes box at the top; create files and folders with the buttons in the header; right-click any entry to rename, delete, or bookmark it. The vault path at the bottom opens Settings when clicked.

Bookmarks

Right-click a note (or use Bookmark this note in the palette) to pin it. Bookmarked notes stay in a Bookmarks section at the top of the sidebar, across vaults and restarts. Use it for the notes you open every day: a daily note, a task list, an index.

Graph view

Graph in the toolbar (or the palette) draws the vault as a force graph. Drag to pan, scroll to zoom, click a node to open that note. Orphan notes sit at the edge — a quick way to spot writing that never got connected.

Zen mode

Zen mode hides the sidebar and toolbar so only the current note fills the window. Toggle it from the toolbar sun icon or the command palette; the setting is remembered. Leave zen mode the same way.

Read-only view

⌘E / Ctrl+E locks the editor. Blocks render without their controls, which makes the note calm to read and safe to scroll with a cat on your lap. Toggle back to edit. The lock state is per session, not saved with the vault.

Light and dark

KbWrite ships a dark theme and a light theme; switch from the command palette (Switch to light mode). Fonts, font size, and custom CSS are in Settings.
