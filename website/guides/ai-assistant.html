Work with an AI assistant

KbWrite's built-in MCP server hands your assistant the vault — read, search, create, and edit — without any of it leaving your machine.

1. Start the server

Settings → MCP server → Start. It serves the open vault on http://127.0.0.1:47321/mcp and stops when KbWrite quits. See the MCP reference for details.

2. Connect your assistant

Run the matching command once:

claude mcp add --transport http kbwrite http://127.0.0.1:47321/mcp   # Claude Code
codex mcp add kbwrite --url http://127.0.0.1:47321/mcp               # Codex
opencode mcp add kbwrite --url http://127.0.0.1:47321/mcp            # OpenCode

Start a session in the assistant; the kbwrite tools should appear.

3. Jobs it is good at

Ask forWhy it works
"Summarize everything I wrote this week"list_notes + search_notes over your daily notes.
"Find notes about pricing and write an overview note linking them"Search plus create_note — the assistant does the reading, you get a hub note.
"Turn the tasks in my daily notes into one checklist"Reads several notes, writes one tidy summary note.
"This PDF is attached in Meeting X — extract the action items"Reads the note, reasons over the content, appends a section.
"Fix broken wikilinks to [[Projekt Alpha]]"Search catches the typos, write_note repairs them — review the diff in KbWrite after.

4. Keep the loop tight

Let the assistant write to new notes or append clearly-marked sections, then review in KbWrite. Since the vault is plain files, you can also let git (see the git guide) record every machine-made change — revert with one command if an edit misses the mark.

Privacy: the server only exposes the open vault, only on 127.0.0.1, and only while KbWrite runs. What the assistant does with note contents afterward is between you and that assistant's provider.

Beyond the built-in tools

If the six tools are not enough, a Rust plugin can add vault-aware commands with custom dialogs — a nightly summarizer, a tagger, an importer. The plugin API mirrors what the MCP server exposes and runs inside the app.
