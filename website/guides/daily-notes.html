Daily notes that stick

A journal you will still be writing in next month.

The structure

Keep dated notes in their own folder so they never crowd the rest of the vault:

Journal/
  2026-10-26.md
  2026-10-27.md

Create today's note each morning: new folder Journal once, then a new YYYY-MM-DD.md inside it. Name notes by date and ⌘O finds any day instantly — type 1027 and today's note is the top hit.

A template worth copying

# 2026-10-27

To-dos are first-class blocks — check them off in the editor. Anything that grows beyond a bullet becomes its own note, linked from the day.

Pin it

Bookmark yesterday's note and today's note. Each morning: create today's, unbookmark yesterday's, bookmark the new one. Two clicks, and the sidebar always opens where you are working.

The weekly review

Friday afternoon, ten minutes:

  1. ⌘O → open each day of the week; skim for unfinished [ ] items.
  2. Move anything real onto next week's list; delete the rest without guilt.
  3. ⌘⇧F → search the week's notes for recurring topics. If one keeps appearing, it deserves a note of its own.
  4. Look at the graph — days that link to many notes are where the real work happened.
Habit trick: keep the journal in zen mode during morning writing. No sidebar, no toolbar — the page looks like paper and the shortcut out (⌘P → Zen mode) is always there.

When a daily note is not enough

For project work that spans weeks, keep a per-project note and link the daily entries into it. The daily notes become a log; the project note stays the map. The AI assistant guide shows how to have an assistant summarize a week of daily notes into a project update.
