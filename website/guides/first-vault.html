Set up your first vault

Ten minutes now, and the vault will still make sense in a year.

1. Install and open

Install with the one-line command for your platform and open KbWrite.

2. Pick the folder

The default vault lives at Documents/KbWriteVault. If you would rather keep notes somewhere else — an existing folder, a synced drive, a git repository — open Settings (⌘,) and set the path. KbWrite reads whatever markdown is already there.

Rule of thumb: choose a folder you would be happy to back up and sync. Since notes are plain files, any folder works — including one in Dropbox, iCloud Drive, or a git clone.

3. Create the three starter notes

Press ⌘N and make these:

  • Home — your index. Links to the areas of life or work you keep notes about.
  • Inbox — where unsorted thoughts land. Empty it during a weekly review.
  • Journal — or use the daily notes guide for a dated folder instead.

In Home, link them so the graph has roots:

# Home

- [[Inbox]] — everything lands here first
- [[Journal]] — one note per day
- Projects: [[Website redesign]], [[Learning Rust]]

4. Bookmark what you open daily

Right-click Home and Bookmark it (or open it and run Bookmark this note from ⌘P). Bookmarked notes pin to the top of the sidebar — do the same for Inbox and Journal and the app now opens straight into your workflow.

5. Write the way you will actually write

  • Capture fast: new thought → ⌘N or straight into Inbox.
  • Link while writing: type [[ and let completion find the note.
  • Let structure emerge: add a heading or a new note only when a topic keeps coming back.

6. Look around

After a few notes, open Graph from the toolbar to see what connects. Press ⌘P to skim every command — formatting, view modes, search. Set your fonts and maybe a line of custom CSS in Settings.

That is the whole loop: capture, link, review. Everything else is optional.
