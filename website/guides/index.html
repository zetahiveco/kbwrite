Coming from Obsidian?

A vault of markdown files opens in KbWrite as-is — point Settings at the folder and go. Wikilinks resolve against note names, frontmatter stays in the file, and attachments travel with the folder. What differs: KbWrite edits with blocks, ships a graph and full-text search built in, and extends through Rust plugins instead of JavaScript ones.

Patterns worth stealing

  • One idea per note. Small notes link better than big ones — the graph is more useful when nodes are specific.
  • Link as you write. A [[wikilink]] costs a second now and pays off every time you search or open the graph later.
  • Bookmark the notes you open daily. The sidebar keeps them one glance away.
  • Let the machine help. The MCP server turns the vault into a workspace your assistant can search and tidy.
