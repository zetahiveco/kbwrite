Notes that stay on your machine.

A local knowledge base with a block editor. Every note is a markdown file in a folder you choose.

Install

curl -fsSL https://kbwrite.ink/install.sh | sh

Copies KbWrite into your Applications folder. Apple silicon and Intel are detected.

curl -fsSL https://kbwrite.ink/install.sh | sh

Installs the latest build to ~/.local/bin/kbwrite.

irm https://kbwrite.ink/install.ps1 | iex

Run this in PowerShell. It downloads the installer and opens it.

  • Markdown vaultEvery note is a .md file on disk. Point KbWrite at any folder.
  • Block editorType / for headings, lists, to-dos, tables, images, and more.
  • Math & diagramsInline $x^2$ and $$ … $$ blocks render with KaTeX. Mermaid fences become live diagrams.
  • Code highlightingCode blocks are highlighted with Shiki and a language picker.
  • Command palette⌘P for commands, ⌘O to jump to a file, ⌘⇧F to search every note.
  • Wikilinks & graphLink with [[Note]] and see the vault as a graph.
  • Bookmarks & zen modePin notes to the top of the sidebar, or hide everything but the note.
  • Make it yoursPick fonts and font size, add custom CSS, auto-format with Prettier.
  • PluginsRust plugins add commands, dialogs, and block types. Install from a folder or GitHub.
  • MCP serverLet Claude, Codex, or OpenCode read and write the vault.
