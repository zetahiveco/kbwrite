KbWrite

Notes that stay on your machine.

A local knowledge base with a block editor. Every note is a markdown file in a folder you choose.

Install

curl -fsSL https://kbwrite.ink/install.sh | sh

Copies KbWrite into your Applications folder. Apple silicon and Intel are detected.

curl -fsSL https://kbwrite.ink/install.sh | sh

Installs the latest build to ~/.local/bin/kbwrite.

irm https://kbwrite.ink/install.ps1 | iex

Run this in PowerShell. It downloads the installer and opens it.

  • Markdown files on disk
  • Block editor, type /
  • Wikilinks and a graph
  • Rust plugins
