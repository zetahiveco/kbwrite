KbWrite

Plugins

A KbWrite plugin is a Rust library. It loads inside the app and uses the plugin API to read and write notes, and to add commands. Plugins are native code: install only the ones you trust.

Install

Open Settings, then either:

  • Choose the plugin folder. That folder must contain manifest.toml.
  • Paste a GitHub URL, such as https://github.com/owner/repo. KbWrite downloads the repository, finds manifest.toml, and builds the plugin with Cargo when the library is not already there.

Installed plugins live in ~/.kbwrite/plugins. Disable or remove them from Settings. Commands a plugin registers show up on its row.

manifest.toml

Every plugin folder needs this file.

id = "hello"
name = "Hello"
version = "0.1.0"
description = "Adds a command that creates a note."
authors = ["Ada"]
min_app_version = "0.5.0"
entry = "hello_plugin"

id is the folder name KbWrite uses. entry is the library name from Cargo, without lib or an extension. A crate named hello_plugin produces libhello_plugin.dylib on macOS, libhello_plugin.so on Linux, and hello_plugin.dll on Windows.

The API

Depend on kbwrite-plugin and export one type with export_plugin!. From this repository: 

kbwrite-plugin = { path = "../../src-tauri/plugin-api" }

From a plugin of your own, point Cargo at the git package:

kbwrite-plugin = { git = "https://github.com/zetahiveco/kbwrite", package = "kbwrite-plugin" }

Api can:

  • vault_path — absolute path of the open vault
  • notes — relative paths of every markdown note
  • read_note / write_note — read or replace a note
  • create_note — add a note in the vault root
  • delete_path — delete a note or folder inside the vault
  • log — show a short message in KbWrite
  • register_command — add a button in Settings

Paths may be relative (Plan.md or Plan) or absolute, and must stay inside the vault.

Example

A working sample is in plugins/example. The library looks like this: 

use kbwrite_plugin::{export_plugin, Api, Plugin};

#[derive(Default)]
struct Hello;

impl Plugin for Hello {
    fn load(&mut self, api: &Api) {
        let _ = api.register_command("hello", "Write hello note");
    }

    fn command(&mut self, api: &Api, id: &str) {
        if id == "hello" {
            match api.create_note("Hello from plugin", "Written by the Hello plugin.\n") {
                Ok(path) => api.log(&format!("Created {path}")),
                Err(error) => api.log(&error),
            }
        }
    }
}

export_plugin!(Hello);

Build it, or let Settings build it when you install the folder:

cargo build --release

The dynamic library exports kbwrite_plugin_vtable. KbWrite calls load when the plugin is enabled, command when you run a command, and unload when you disable or remove it.
